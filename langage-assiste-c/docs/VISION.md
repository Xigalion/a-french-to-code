# Vision — Langage assisté C

## Objectif
Permettre d'apprendre à programmer en C17 en formulant des instructions en français contrôlé, sans masquer les concepts ni corriger silencieusement la logique du programmeur.

## Principes
- Le code C est la source exécutable et modifiable.
- Chaque instruction française validée devient un commentaire immédiatement au-dessus du code généré.
- Une instruction de base correspond à une opération élémentaire.
- La traduction est fidèle : aucune variable, conversion, boucle ou décision algorithmique n'est inventée.
- Les erreurs de compréhension sont distinctes des diagnostics de compilation et d'exécution.
- Le système fonctionne localement ; l'extension VS Code est une interface au-dessus du moteur.
- La version stricte reste disponible même lorsque des niveaux plus permissifs apparaissent.

## Public
Débutants en C, étudiants en systèmes et embarqué, enseignants, développeurs souhaitant découvrir le langage.

## Hors périmètre initial
Génération de projets entiers, agents autonomes, traduction multilangage, synonymes illimités, réparation automatique du code.
